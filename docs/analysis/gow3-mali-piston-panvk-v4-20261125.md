# 2026-11-25 Mali test: exact 1023daf52 base
- PistonPort 3b0a3d8: adapted on-demand shader index and lazy loading of compatible GoW3 SPIR-V metadata, preserving exact contiguous permutation indices. No shader or pipeline cache from Cars 3. This is **not** the full raw-game shader replay/materialization manifest: GoW3's UBO specialization, replay snapshots, capture data and shader file offsets differ, and no GoW3 manifest has been generated. No cold-cache or FPS claim.
- PanVK V4: stage the original driver package from the SHA-pinned Bachata 0.2.6 APK, with checksum and ARM64 metadata validation. Explicit opt-in, original V3 remains default. V4 release notes identify native image layouts and robust SSBO load vectorization on v11. Mali G720 is v12, so do not claim the v11-only change accelerates it or force that lowering onto v12.
- PistonPort driver hub alternatives: MineGraph panvk.8 (content-addressed BC upload, tiler heap, compatible multi-draw indirect and KRAID; tested G715), JimVulkan r10 (CSF render-target memory reuse correction, lower CPU query wait, G720 MC12 tested). Use existing custom ZIP import; do not merge unvalidated driver patches or enable changes in unrelated drivers. MineGraph batching sets draw ID=0, which must be verified with GoW3 before selecting by default.
- Bloodborne Android's robustness2 workaround already exists in base. Other Bloodborne forks use same V3.2 experimental support; Uncharted Android public port targets Adreno. No verified new Mali renderer optimization from those.
- The new branch deliberately excludes all commits after 1023daf52. No Adreno settings changes.
- CI validates package and compilation; only on-device same-save warm/cold comparison can establish gains or freedom from freezes.
